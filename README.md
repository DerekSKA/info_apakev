# INFO_APAKEV — Infografía sobre seguridad informática

## Descripción del proyecto

Aplicación web educativa desarrollada con React y Vite que explica la tríada CIA de la seguridad informática: **Confidencialidad, Integridad y Disponibilidad**.

El proyecto está dirigido a personas que no tienen conocimientos previos de ciberseguridad. Su objetivo es facilitar la comprensión de estos tres principios mediante definiciones sencillas, ejemplos cotidianos y recomendaciones de protección.

- React

## Contenido de la infografía

1. **Introducción:** explicación de la tríada CIA y su importancia en la seguridad informática.
2. **Confidencialidad:** garantiza que la información solo sea accesible para personas autorizadas.
3. **Integridad:** protege la exactitud de los datos y evita modificaciones no autorizadas.
4. **Disponibilidad:** permite que los usuarios autorizados accedan a la información cuando la necesitan.
5. **Caso práctico:** aplicación de los tres principios a una cuenta bancaria.
6. **Conclusión:** resumen de la importancia de proteger la información digital.

## Ejecución del proyecto en local

### Requisitos

- Node.js
- npm

### Instalación

Desde la carpeta raíz del proyecto, ejecutar:

```bash
npm install
```

### Iniciar el servidor de desarrollo

```bash
npm run dev
```

### Generar la versión de producción

```bash
npm run build
```

Los archivos optimizados para producción se generan en la carpeta `dist`.
