## Descripción del proyecto

INFO_APAKEV es una aplicación web educativa que explica la tríada CIA de la seguridad informática: **Confidencialidad, Integridad y Disponibilidad**.

El proyecto está dirigido a personas que no poseen conocimientos previos sobre ciberseguridad. Mediante una infografía visual, organizada y fácil de comprender, se presentan los tres principios fundamentales de la seguridad de la información, sus aplicaciones y algunas medidas básicas de protección.

La aplicación utiliza ejemplos cotidianos para facilitar la comprensión de los conceptos y demostrar su importancia en la protección de los datos y los sistemas digitales.

## Objetivo general

Desarrollar una aplicación web informativa que permita comprender los principios fundamentales de la seguridad informática mediante una presentación visual, clara y accesible.

## Fundamentos teóricos

La tríada CIA es un modelo de referencia utilizado en seguridad de la información. Su nombre proviene de los términos en inglés *Confidentiality, Integrity and Availability*.

### 1. Confidencialidad

Garantiza que la información solo sea accesible para las personas, sistemas o entidades autorizadas.

**Ejemplo:** proteger una cuenta bancaria mediante contraseñas seguras y autenticación multifactor.

**Medidas de protección:**

- Utilizar contraseñas seguras y únicas.
- Activar la autenticación multifactor.
- Cifrar información sensible.
- Limitar los permisos de acceso.

### 2. Integridad

Busca mantener la exactitud de la información y evitar modificaciones o eliminaciones no autorizadas.

**Ejemplo:** impedir que los saldos o movimientos de una cuenta bancaria sean alterados sin autorización.

**Medidas de protección:**

- Controlar los permisos de edición.
- Registrar los cambios realizados.
- Utilizar mecanismos de verificación de datos.
- Mantener copias de seguridad.

### 3. Disponibilidad

Busca garantizar que los sistemas, servicios y datos estén accesibles para los usuarios autorizados cuando los necesiten.

**Ejemplo:** poder acceder a una aplicación bancaria para consultar el saldo o realizar una operación.

**Medidas de protección:**

- Mantener los sistemas actualizados.
- Realizar copias de seguridad.
- Supervisar fallos y posibles ataques.
- Preparar planes de recuperación.

## Instalación y ejecución

### Requisitos previos

- [Node.js](https://nodejs.org/)
- npm, incluido con Node.js.
- Git, si deseas clonar el repositorio.

### 1. Clonar el repositorio

```bash
git clone https://github.com/DerekSKA/info_apakev.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd info_apakev
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar en modo desarrollo

```bash
npm run dev
```

Vite mostrará una dirección local en la terminal, normalmente `http://localhost:5173/`, donde podrás visualizar la aplicación.

### 5. Generar la versión de producción

```bash
npm run build
```

Los archivos optimizados se generarán en la carpeta `dist`.

## Objetivos de aprendizaje

Con esta infografía se busca que los usuarios puedan:

- Comprender qué significa cada principio de la tríada CIA.
- Diferenciar la confidencialidad, la integridad y la disponibilidad.
- Reconocer ejemplos de estos principios en servicios digitales.
- Identificar medidas básicas de protección de la información.
- Entender por qué los tres principios se complementan.

## Conclusión

La tríada CIA constituye una referencia fundamental para comprender la seguridad de la información.

La **confidencialidad** protege los datos frente al acceso no autorizado, la **integridad** ayuda a mantenerlos correctos y la **disponibilidad** permite acceder a ellos cuando se necesitan.

Estos principios se complementan y deben considerarse conjuntamente para proteger adecuadamente la información y los sistemas digitales.
